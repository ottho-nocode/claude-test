# Transcriptions

Placez vos transcriptions de réunions clients ici.

## Format attendu

Les transcriptions doivent être au format **Markdown** (.md)

## Structure recommandée

```markdown
# Titre du projet client

**Meeting Date:** JJ MMM, YYYY - HH:MM AM/PM

---

**Participant 1** *[MM:SS]*: Contenu de la conversation...
**Participant 2** *[MM:SS]*: Réponse...
```

## Exemple

Un exemple de transcription est fourni dans `example-transcription.md`

## Naming convention

Nommez vos fichiers de manière descriptive :
- `projet-client-reunion-1.md`
- `projet-ecommerce-brief-initial.md`
- etc.
