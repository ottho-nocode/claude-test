# Templates

## Template de cahier des charges

Placez votre template de cahier des charges PDF dans ce dossier.

### Fichier attendu

- **Nom du fichier** : `template-cahier-des-charges.pdf`
- **Format** : PDF

Le système extraira automatiquement la structure et le contenu de ce template pour générer les cahiers des charges des projets clients.

### Note

Si vous n'avez pas encore de template, le système peut en générer un basique. Cependant, utiliser votre propre template garantit que les documents générés suivent exactement votre format habituel.
